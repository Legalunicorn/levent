Quick guide for iPhone
  1. Save the private Excel (.xlsx) or CSV file to the Files app.
  2. Open this website in Safari. Tap Import guest list and choose the Excel or CSV file.
  3. Search for a guest and tap their card. Every edit saves automatically when storage is available.
  4. Meal numbers are portions remaining. Red choices are unavailable; you can keep a guest’s existing choice.
  5. Use Export backup, then save the downloaded JSON to Files. Use Restore backup to bring it back.
